## CI

- Continuous Intergration (지속적 통합)

코드를 합칠 때마다 자동으로 검사 및 빌드

목적: 작은 변경을 자주 통합하고, 자동 검증으로 문제를 일찍 발견하기

잘못된 코드가 main에 합쳐지지 않도록 함

## 워크플로(Workflow)

.github/workflows/*.yml 파일 하나 = 워크플로 하나

실습파일 확인 -> cat .github/workflows/build.yml

#오늘 한 것

- 워크플로 실습

- 오류 -> 해결 방법 실습

- main 브랜티 보호 (README.md 작성 방법 변화)

- 오류 해결 브랜치 작성 후 머지 등등
