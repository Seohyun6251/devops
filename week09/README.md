## 쿠버네티스
### 컨테이너화된 애플리케이션 배포, 확장,관리를 자동으로 처리해주는 오픈 시스템

- Orchestration: 여러 서버의 컨테이너들을 자동으로 배치하고 관리하는 것

- 선언형/명령형
명령형 = "이렇게 해라"
선언형 = "이런 상태를 원한다"

## 용어정리
- 클러스터
1개 이상의 노드로 구성된 쿠버네티스 관리 환경

- Control Plane
클러스터를 관리하는 두뇌

- 노드
컨테이너가 실제로 도는 서버

- Pod
컨테이너를 감싸는 최소 단위

- 네임스페이스
클러스터 안의 칸막이

- kubectl
클러스터에 명령을 보내는 도구
